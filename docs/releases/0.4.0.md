# Votre espace personnel, sur votre ordinateur

- Créez votre compte au premier lancement : nom, adresse e-mail et mot de passe confirmé (12 caractères minimum).
- Connectez-vous ensuite avec ces identifiants, sans hébergement ni validation par e-mail.
- Votre mot de passe est protégé par une empreinte Argon2id ; vos dossiers restent dans la base locale.
- L’espace personnel commence vide et ne permet aucune connexion de démonstration. Un seul propriétaire peut être créé.
- Le compte et les dossiers sont conservés après redémarrage et lors des mises à jour. Les anciennes données de démonstration restent séparées et conservées.

L’adresse e-mail sert d’identifiant uniquement. Cette version ne propose pas de récupération du mot de passe par e-mail. La connexion ne chiffre pas les fichiers sur le disque.

Depuis la version 0.3, utilisez l’icône de mise à jour puis **Installer et redémarrer**. Pour une première installation, téléchargez l’installateur Windows ci-dessous.
