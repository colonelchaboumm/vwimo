Application Windows autonome et mises à jour intégrées.

- Le backend démarre et s’arrête avec l’application : Python et Node ne sont plus nécessaires sur le poste utilisateur.
- L’icône de téléchargement signale une nouvelle version. Un clic ouvre les notes ; « Installer et redémarrer » lance la mise à jour.
- Les mises à jour sont vérifiées par signature cryptographique avant installation.
- Les données sont conservées dans le profil Windows, hors du dossier d’installation. Une sauvegarde précède les migrations de schéma.
- Recherche automatique des nouvelles versions au démarrage et périodiquement ; vérification manuelle disponible dès l’écran de connexion.

Installer cette version une première fois pour activer les futures mises à jour intégrées. L’application autonome reste en mode démonstration ; les intégrations IA et Outlook ne sont pas encore activées. La signature de mise à jour ne constitue pas un certificat Windows Authenticode.
