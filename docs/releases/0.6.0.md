# Charlie prépare vos dossiers

- Nouvelle page Charlie : briefing, synthèses de contacts, mandats, estimations et rapprochements, brouillons d’annonces et d’e-mails à relire.
- Mode local fondé sur des règles, sans modèle d’IA ni appel externe.
- Génération OpenAI facultative avec votre clé API, contexte visible et confirmation avant chaque transmission. Seuls le message courant et le contexte choisi sont envoyés ; l’historique reste local.
- Conversations privées conservées sur votre poste ; clé API protégée par votre profil Windows avec DPAPI.
- Protection contre les demandes répétées après une interruption réseau, conflits de contexte et configurations non testées signalés explicitement.

Charlie ne modifie aucun dossier et n’envoie aucun e-mail. Outlook, l’analyse de documents, le radar et les campagnes restent à venir. Les réponses OpenAI ont été simulées dans les tests : utilisez le bouton de test pour vérifier votre propre clé et votre accès API.

Les comptes, dossiers et documents existants sont conservés. Une sauvegarde est créée avant migration locale. Après installation, reconnectez-vous à votre compte habituel.
